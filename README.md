## Concepts covered

1. **Arrays:** insertion, deletion, search, update, display and sorting.
2. **Hashing:** modulo hash function and collision handling with linear probing.
3. **Search and Sorting:** Sentinel Search, Bubble Sort and Selection Sort.
4. **Linked List:** Call Log Management using a singly linked list.
5. **Stack:** Stack implementation using two queues.
6. **Queue:** Queue implementation using a linked list.
7. **Trees:** Binary Search Tree insertion, search and tree traversals.
8. **Graph:** Adjacency-list representation, Breadth-First Search (BFS) and Depth-First Search (DFS).

## Compile and run

Install a C++ compiler such as g++. Compile one assignment at a time:

    g++ -std=c++17 -Wall -Wextra source_file.cpp -o program

Run on Linux/macOS:

    ./program

Run on Windows PowerShell:

    .\program.exe

Each source file has its own main() function and should be compiled separately.
